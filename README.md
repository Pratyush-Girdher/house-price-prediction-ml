
# House Price Prediction - Machine Learning

This project builds a regression model to predict house prices using Python, pandas, and scikit-learn. The workflow includes data cleaning, feature selection, training Decision Tree and Random Forest models, hyperparameter tuning to reduce overfitting, and evaluation using Mean Absolute Error (MAE).

## Skills & Tools
- Python
- pandas
- scikit-learn
- NumPy
- Jupyter Notebook

## What I Learned
- End-to-end machine learning workflow
- Working with real-world datasets
- Model validation and performance evaluation
- Overfitting control using model tuning
